# Project Name
 FitLog

# Short Description
FitLog is a modern, dark-themed workout library and exercise planning web application built with Next.js and Tailwind CSS, designed to help users easily browse, plan, and manage their daily workouts.

## Technologies Used
* Next.js
* TypeScript
* Tailwind CSS
* DaisyUI
* React Icon
* React Tosttify

## Key Features
1. **Dynamic Workout Library**: Fetches and displays a comprehensive list of workouts and exercises dynamically from the API.
2. **Dynamic Routing & Details Page**: Implements dynamic routing (`/workouts/[id]`) to show specific and detailed views for each workout.
3. **My-Plan Management**: Allows users to create, organize, and manage their personalized workout plans and routines.
4. **Responsive Modern UI**: Built with Tailwind CSS and daisyUI for a sleek, clean, and attractive dark-themed interface.
5. **Component-Based Architecture**: Utilizes modular and reusable components like Navbar, Footer, Banner, and LibrarySection for clean code maintenance.
